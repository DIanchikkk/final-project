# todo

Учебный веб-проект для планирования задач.  
Приложение позволяет создавать задачи, просматривать список задач, редактировать и удалять их, а также отмечать задачи как выполненные.

Поддерживаются и одноразовые, и повторяющиеся задачи с различными правилами повторения.

## Выполненные задания со звёздочкой

В проекте выполнены следующие задания повышенной сложности:

- реализованы расширенные правила повторения задач:
  - по дням недели (`w`)
  - по дням месяца (`m`)
- реализована аутентификация по паролю через переменную окружения `TODO_PASSWORD`
- реализована защита API-эндпоинтов с помощью middleware
- реализована возможность задавать порт сервера через переменную окружения `TODO_PORT`
- реализована возможность задавать путь к файлу базы данных через переменную окружения `TODO_DBFILE`
- реализована сборка и запуск проекта в Docker-контейнере

### Переменные окружения

Проект поддерживает следующие переменные окружения:

- `TODO_PORT` — порт, на котором запускается сервер
- `TODO_DBFILE` — путь к файлу базы данных SQLite
- `TODO_PASSWORD` — пароль для входа в приложение  
  (если переменная не задана, авторизация отключена)

Пример настройки переменных окружения:

```bash
export TODO_PORT=7540
export TODO_DBFILE=scheduler.db
export TODO_PASSWORD=12345
```
